Solução para a operação cascata IBS e CBS — correção dos parâmetros e recálculo da etapa 17.

Raiz do problema — campo único, dois significados conflitantes
Campo "alíquota" da cascata armazena: IBS → 10% ← peso de distribuição, não taxa CBS → 90% ← peso de distribuição, não taxa Resultado: CBS = 120.445,93 × 90% = R$ 108.401,34 ✗ (≈ base inteira) IBS = 120.445,93 × 10% = R$ 12.044,59 ✗
Solução — separar alíquota_combinada dos pesos
Introduzir um único parâmetro novo no sistema: alíquota_combinada
alíquota_combinada = 1,00% ← parâmetro a criar/informar peso_CBS = 90% ← já existe, não muda peso_IBS = 10% ← já existe, não muda CBS_alíquota = alíquota_combinada × peso_CBS = 1,00% × 90% = 0,90% IBS_alíquota = alíquota_combinada × peso_IBS = 1,00% × 10% = 0,10%
Parâmetros antes × depois
alíquota_combinada novo — → 1,00%
CBS — campo alíquota 90% → 0,90%
IBS — campo alíquota 10% → 0,10%
CBS — peso distribuição 90% → 90% (inalterado)
IBS — peso distribuição 10% → 10% (inalterado)
